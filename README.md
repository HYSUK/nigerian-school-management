# 🏫 Nigerian Hybrid School Management System

A hybrid school administration infrastructure featuring a **JavaFX Desktop Application** for local offline management and a **FastAPI / Supabase Cloud Gateway** for real-time web portal sync.

## 🛠️ Tech Stack
* **Desktop App:** JavaFX 21, JDBC, SQL Server
* **Cloud Backend:** Python (FastAPI), Uvicorn, PostgreSQL (Supabase)
* **Templating:** Jinja2, HTML5/CSS3

# Install dependencies
